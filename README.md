# Zomato-clone-Using-HTML-only

🍔 Zomato Clone – Built with Just HTML!

This is a simple Zomato homepage clone that I created using only HTML (with some CSS and JavaScript for styling and basic animations).

The idea was to practice building real-world layouts using basic web technologies — no frameworks, no libraries. Just clean, beginner-friendly code.

✨ What's included:
- Zomato-style layout with logo, navbar, and hero section
- Highlights of food delivery features
- A call-to-action section with input & button
- Fully styled with CSS (red theme inspired by Zomato)
- A little JavaScript for animation (typing effect)

📌 Why I made this:
I’m learning front-end development and wanted to build something cool with just HTML to improve my structure and layout skills.

For JS I used AI tool.
